# testpress — редизайн ПРЕСС-ОН

React-редизайн сайта [press-on.ru](https://www.press-on.ru).

Исходные HTML-страницы сохранены в `_source/`. Приложение — в папке `web/`.

```bash
cd web
npm install
npm run dev
```

## GitHub Pages

Инструкция: [docs/GITHUB_PAGES.md](docs/GITHUB_PAGES.md).  
После push в `main` сайт публикуется автоматически (workflow в `.github/workflows/deploy-pages.yml`).

Сайт: https://thechattytongue.github.io/testpress/
